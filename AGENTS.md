# Instruções do projeto

## Documentação das alterações

- Crie a pasta `MD/` na raiz do projeto caso ela não exista.
- Documente nessa pasta todas as alterações realizadas no projeto, incluindo código, configurações, recursos e documentação.
- Use arquivos Markdown com nomes descritivos e data no formato `AAAA-MM-DD-descricao.md`.
- Registre o que foi alterado, o motivo e as validações realizadas. Informe limitações ou verificações pendentes quando houver.
- Atualize o documento da tarefa ao concluir o trabalho para refletir o resultado final.

## Mensagem de commit

- Ao final de todas as respostas finais ao usuário, sugira uma mensagem curta de commit em português, coerente com o trabalho realizado.
- Apresente a sugestão com o prefixo “Commit sugerido:”, seguido da mensagem curta entre crases.
- Não execute commits automaticamente; somente quando o usuário solicitar.
