# Aulas por classe

Esta pasta contém uma aula consolidada para cada classe criada ou afetada pelas alterações do projeto. As instruções completas estão no [AGENTS.md](../../AGENTS.md).

Cada aula deve usar o nome totalmente qualificado da classe, por exemplo `com.example.samplestickerapp.CropVideoActivity.md`, e informar o caminho do código e a última atualização. Ela deve explicar os conceitos, algoritmos, lógica, padrões e arquitetura efetivamente presentes na classe, com fundamentos, exemplos, fluxos e análise dos métodos e de suas colaborações. Não deve se limitar às linhas alteradas.

Atualize o mesmo documento quando a classe mudar. Não leia esta pasta para obter contexto sem solicitação explícita do usuário; a leitura pontual de uma aula da classe afetada é permitida somente para mantê-la atualizada na tarefa atual.

Esta tarefa alterou somente documentação; nenhuma classe foi modificada e nenhuma aula de classe foi criada artificialmente. As aulas serão produzidas conforme as classes forem afetadas nas próximas alterações.
